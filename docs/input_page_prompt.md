# Input page prompt

```
Design the input page of "Entropy Zero", a passive shelter design tool for DRDO.
Clean, light, professional. A single centred form, about 720 px wide. No 3D, no
results; the output is a separate page.

BASIC (always visible)
- Location: Leh, Ladakh · 3,256 m
- What it is for: Troop accommodation (selected), Medical post, Command post,
  Cookhouse and mess, Workshop, Unheated store, Family relief shelter
- People: 10

SHAPE (expandable)
- Orientation: 180° (glazing faces south), shown as a small compass
- Floor area: 90 m²
- Plan proportion: 2.2 : 1
- Ceiling height: 2.6 m
- Arrangement: Single room, Sunspace (selected), Trombe wall, Vestibule
- Glazing: South low-e argon, East and West double clear
- Night shutters: on, south windows

ADVANCED (collapsed)
- Air leakage: 0.50 ACH
- Minimum fresh air: 0.35 ACH
- Comfort target: IMAC 2016 (note: IMAC-R 2022 currently gives the same result)

SEARCH
- Search size: 100 designs (≈ 6 min), 300 (≈ 18 min), 500 (≈ 31 min)
- Button: "Find the best shelter" (opens the output page)

RULES
- Do not ask for weather, altitude or material properties.
- No temperatures, costs, scores or 3D on this page.
```
